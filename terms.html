利用規約

最終更新日: 2026年9月13日

本利用規約（以下「本規約」といいます。）は、弓道部的中ノート（以下「本サービス」といいます。）の提供者（以下「運営者」といいます。運営者の氏名は、本サービスのプライバシーポリシーに定めるところにより開示します。）が提供する本サービスの利用に関する条件を、運営者と利用者との間において定めるものです。

第1章 総則

第1条（目的）

1. 本規約は、本サービスの提供条件及び本サービスの利用に関する運営者と利用者との間の権利義務関係を定めることを目的とします。

2. 利用者は、本規約の全ての条項に同意したうえで本サービスを利用するものとします。本サービスの利用を開始した時点で、利用者は本規約に同意したものとみなされます。

第2条（定義）

本規約において使用する用語の定義は、次の各号に定めるとおりとします。

1. 「本サービス」とは、名称の如何を問わず、運営者が提供する弓道の的中記録の管理に関するアプリケーション及びこれに付随する一切のサービスをいいます。

2. 「利用者」とは、本規約に同意し、本サービスを利用する全ての者をいい、団体利用者及び部員利用者を含みます。

3. 「団体利用者」とは、第6条に定める利用登録を完了し、団体アカウントを保有する者をいいます。

4. 「部員利用者」とは、団体利用者が登録した個人識別情報を用いて本サービスを利用する者をいいます。

5. 「団体アカウント」とは、電子メールアドレス及びパスワードによる認証を経て本サービスを利用するための地位をいい、部員の登録及び削除、記録の編集その他の管理権限を伴うものをいいます。

6. 「団体ID」とは、団体アカウントごとに付与される識別符号をいいます。

7. 「個人ID」とは、団体利用者が部員を登録した際に付与される識別符号をいいます。

8. 「団体データ」とは、団体アカウントのもとに登録され、又は本サービスの利用に伴い生成される部員情報、的中記録、出欠記録、立順その他一切のデータをいいます。

9. 「生成AI機能」とは、第12条に定める人工知能技術を利用した機能をいいます。

10. 「外部サービス」とは、本サービスの提供のために運営者が利用する第三者の提供するサービスをいいます。

11. 「消費者」とは、消費者契約法第2条第1項に定める消費者をいいます。

第3条（本規約の適用）

1. 本規約は、本サービスの利用に関する運営者と利用者との間の一切の関係に適用されます。

2. 運営者が本サービス上又は運営者の運営するウェブサイト上に掲示する個別規定、ガイドライン、注意事項その他の定め（以下「個別規定等」といいます。）は、名称の如何にかかわらず本規約の一部を構成するものとします。

3. 本規約の定めと個別規定等の定めとが異なる場合には、個別規定等の定めが優先して適用されるものとします。

4. 本サービスは、日本国内における利用を前提として提供されます。日本国外から本サービスを利用する場合、利用者は、当該国又は地域の法令を遵守する責任を自ら負うものとします。

第4条（本規約の変更）

1. 運営者は、次の各号のいずれかに該当する場合には、民法第548条の4の規定に基づき、利用者の個別の同意を要することなく本規約を変更することができるものとします。

  • (1) 本規約の変更が利用者の一般の利益に適合するとき。
  • (2) 本規約の変更が契約をした目的に反せず、かつ、変更の必要性、変更後の内容の相当性その他の変更に係る事情に照らして合理的なものであるとき。

2. 運営者は、前項の変更を行う場合、変更後の本規約の内容及び効力発生時期を、効力発生時期が到来するまでに、本サービス上又は運営者の運営するウェブサイト上への掲示その他の適切な方法により周知するものとします。

3. 変更後の本規約は、前項により周知された効力発生時期から適用されるものとします。効力発生時期の到来後に利用者が本サービスを利用した場合、当該利用者は変更後の本規約に同意したものとみなされます。

第5条（通知又は連絡）

1. 運営者から利用者に対する通知又は連絡は、本サービス上への掲示、電子メールの送信その他運営者が適当と判断する方法により行うものとします。

2. 前項の通知又は連絡は、本サービス上に掲示した時点又は運営者が電子メールを発信した時点をもって、利用者に到達したものとみなします。

3. 利用者から運営者に対する通知又は連絡は、本サービス内のお問い合わせフォーム又は第31条に定める窓口宛ての電子メールによるものとし、運営者が別途指定する場合を除き、その他の方法による通知又は連絡の効力を認めないものとします。

4. 利用者は、登録した電子メールアドレスその他の連絡先に変更が生じた場合、遅滞なく運営者所定の方法によりこれを届け出るものとします。当該届出を怠ったことにより通知又は連絡が到達しなかった場合であっても、前項の定めにかかわらず、通常到達すべき時に到達したものとみなします。

第2章 利用契約

第6条（利用登録）

1. 団体アカウントの登録は、当該団体を代表する権限又は当該団体の運営に関する管理権限を有する者が行うものとします。

2. 登録を希望する者は、本規約に同意のうえ、運営者所定の方法により、真実、正確かつ最新の情報を届け出るものとします。

3. 運営者は、登録を希望する者が次の各号のいずれかに該当すると判断した場合、登録を承認せず、又は登録後にこれを取り消すことができるものとし、その理由について開示する義務を負わないものとします。

  • (1) 届け出た情報の全部又は一部につき、虚偽、誤記又は記載漏れがあった場合
  • (2) 過去に本規約その他運営者の定める規約等に違反したことがある場合
  • (3) 第24条第1項各号に定める反社会的勢力等に該当し、又は関与していると運営者が判断した場合
  • (4) 未成年者、成年被後見人、被保佐人又は被補助人のいずれかであり、法定代理人、後見人、保佐人又は補助人の同意等を得ていない場合
  • (5) その他、運営者が登録を相当でないと判断した場合

4. 登録は、運営者が承認の意思表示を行った時点をもって完了し、当該時点において本規約を内容とする利用契約が運営者と団体利用者との間に成立するものとします。

第7条（登録事項の変更）

1. 利用者は、登録した事項に変更が生じた場合、遅滞なく運営者所定の方法により変更の届出又は登録内容の修正を行うものとします。

2. 前項の届出又は修正を怠ったことにより利用者に生じた不利益について、運営者は責任を負わないものとします。

第8条（アカウントの種別及び権限）

1. 本サービスにおけるアカウントは、団体アカウント及び部員利用の区分により構成されます。

2. 団体利用者は、自らの団体に属する部員の登録、変更及び削除、団体データの閲覧、編集及び削除その他運営者が定める管理操作を行うことができます。

3. 部員利用者は、団体ID及び個人IDを用いて本サービスにアクセスし、自らに関する記録の閲覧及び入力その他運営者が定める範囲の操作を行うことができます。

4. 運営者は、アカウントの種別ごとに利用できる機能の範囲を、事前の通知なく変更することができるものとします。

第9条（ID及びパスワードの管理）

1. 利用者は、自己の責任において、団体ID、パスワード及び個人ID（以下総称して「認証情報」といいます。）を適切に管理及び保管するものとし、これを第三者に利用させ、又は貸与、譲渡、名義変更、売買その他の方法により処分してはならないものとします。ただし、当該団体の運営上必要な範囲において、当該団体に属する関係者に共有する場合はこの限りではありません。

2. 利用者は、団体IDと個人IDの組合せを知得した者が当該団体の団体データにアクセスし得る仕様であることをあらかじめ理解したうえで、認証情報を管理するものとします。

3. 認証情報の管理不十分、使用上の過誤又は第三者の使用等に起因して生じた損害に関する責任は利用者が負うものとし、運営者は、第22条に定める範囲を超えて責任を負わないものとします。

4. 利用者は、認証情報が盗用され、又は第三者に使用されていることが判明した場合、直ちにその旨を運営者に通知するとともに、運営者の指示に従うものとします。

第3章 本サービスの利用

第10条（団体データの取扱い）

1. 団体データの内容、正確性及び適法性については、当該団体データを登録した団体利用者が一切の責任を負うものとします。

2. 団体利用者は、部員の氏名その他の個人情報を本サービスに登録するにあたり、あらかじめ当該本人及び必要に応じてその法定代理人から、登録及び本サービスにおける利用について必要な同意を取得する責任を負うものとします。

3. 運営者は、利用者の同意を得ることなく団体データの内容を閲覧し、又は利用しないものとします。ただし、次の各号のいずれかに該当する場合はこの限りではありません。

  • (1) 本サービスの不具合の調査又は復旧のために必要な場合
  • (2) 本規約に対する違反の有無を調査するために必要な場合
  • (3) 法令に基づく開示要請、裁判所の命令又は行政機関の指導等に応じる必要がある場合
  • (4) 人の生命、身体又は財産の保護のために緊急の必要がある場合

4. 団体データに含まれる個人情報の取扱いについては、別途定めるプライバシーポリシーによるものとします。

第11条（未成年者の利用）

1. 本サービスは、学校の部活動その他の団体における利用を想定して提供されます。

2. 未成年者が本サービスを利用する場合には、あらかじめ法定代理人の同意を得たうえで、当該団体の責任者の管理のもとで利用するものとします。

3. 未成年者であった利用者が成年に達した後に本サービスを利用した場合、当該利用者は、未成年者であった期間中の利用に関する一切の法律行為を追認したものとみなします。

第12条（生成AI機能の利用）

1. 本サービスには、次の各号に掲げる機能（以下総称して「生成AI機能」といいます。）が含まれます。生成AI機能は、Google LLC が提供する Gemini API を利用して提供されます。

  • (1) 対話形式の質問応答機能
  • (2) 画像から立順表を読み取る機能
  • (3) 画像から的中記録表を読み取る機能
  • (4) 画像又はPDFから練習日程を読み取る機能

2. 生成AI機能を利用した場合、利用者が入力した内容、部員の氏名を含む部員一覧、的中記録並びに利用者が選択又は撮影した画像及びPDFファイルが、運営者の運用する中継サーバー（Cloudflare, Inc. が提供する Cloudflare Workers 上で運用するものをいい、送信された内容を保存しません。）を経由して Google LLC に送信されます。運営者は Gemini API について有料の利用形態を選択しており、送信された内容は回答及び読取結果の生成のために処理され、Google LLC のサービスの改善には利用されません。ただし、同社の定める禁止利用の検知及び防止を目的として、一定の期間記録されることがあります。

3. 前項の送信及びこれに伴う個人情報の取扱いの詳細については、別途定めるプライバシーポリシーによるものとします。

4. 生成AI機能により出力される回答、読取結果その他の情報について、運営者は、その正確性、完全性、有用性又は特定目的への適合性を保証しません。利用者は、出力内容を自ら検証したうえで利用するものとします。

5. 運営者は、生成AI機能の全部又は一部を、事前の通知なく変更し、又は提供を終了することができるものとします。

第13条（データのエクスポート及びバックアップ）

1. 利用者は、運営者が提供する機能の範囲において、団体データをエクスポートすることができます。

2. 運営者は、団体データの保存、保管又は復旧について、いかなる保証も行いません。利用者は、自己の責任において、必要な団体データを定期的にエクスポートし、保管するものとします。

3. 通信環境、利用者の端末の状態その他運営者の合理的な支配の及ばない事由に起因する団体データの同期不良、遅延、欠損又は滅失について、運営者は、第22条に定める範囲を超えて責任を負わないものとします。

第14条（利用料金）

2. 運営者は、将来、本サービスの全部又は一部を有償とすることができるものとします。この場合、運営者は、あらかじめ料金、支払方法その他の条件を本サービス上又は運営者の運営するウェブサイト上に掲示するものとします。

第15条（知的財産権）

1. 本サービス並びに本サービスを構成するプログラム、ソースコード、データベース、デザイン、画面表示、文章、画像、商標、ロゴその他一切の構成要素に関する著作権、商標権その他の知的財産権は、運営者又は正当な権利を有する第三者に帰属します。

4. 利用者は、運営者に対し、本サービスの提供、維持、改善及び不具合の調査に必要な範囲において、団体データを無償で使用することを許諾するものとします。

1. 運営者は、利用者が次の各号のいずれかに該当する場合、事前の通知又は催告を要することなく、当該利用者について、本サービスの全部若しくは一部の利用を一時的に停止し、その利用を制限し、又はアカウントを削除することができるものとします。

  • (1) 本規約のいずれかの条項に違反した場合
  • (2) 登録事項に虚偽の事実があることが判明した場合
  • (3) 運営者からの連絡に対し、相当の期間が経過してもなお応答がない場合
  • (4) 最終の利用から相当の期間にわたり本サービスの利用がない場合
  • (5) 第24条第1項各号に定める反社会的勢力等に該当すると判断された場合
  • (6) その他、運営者が本サービスの利用を継続することを相当でないと判断した場合

3. 第1項の措置は、運営者による当該利用者に対する損害賠償請求を妨げるものではありません。

第18条（退会及びアカウントの削除）

1. 団体利用者は、本サービスの設定画面の機能（団体アカウントの管理者モードでのみ利用できます。）により団体アカウントを削除することができるほか、運営者所定の方法により、団体アカウントの削除を申し出ることができます。

2. 運営者は、前項の申出を受けた場合、申出者が正当な権限を有する者であることを確認したうえで、当該団体アカウント及びこれに属する団体データを削除するものとします。

3. 前二項により削除された団体アカウント及び団体データは、利用者において復旧することができません。利用者は、削除に先立ち、必要な団体データをエクスポートするものとします。削除後の団体データの保管及び消去については、プライバシーポリシー第18条に定めます。

4. 退会後も、第29条に定める条項は、なお効力を有するものとします。

第5章 本サービスの提供

第19条（本サービスの提供の停止等）

1. 運営者は、次の各号のいずれかに該当すると判断した場合、事前の通知を要することなく、本サービスの全部又は一部の提供を停止又は中断することができるものとします。

  • (1) 本サービスに係るシステムの保守点検、更新又は障害対応を行う場合
