プライバシーポリシー

最終更新日: 2026年9月24日

本サービスの提供者（以下「運営者」といいます。運営者の氏名は第19条に定めるところにより開示します。）は、弓道部的中ノート（以下「本サービス」といいます。）における個人情報の取扱いについて、個人情報の保護に関する法律（以下「個人情報保護法」といいます。）その他の関係法令及びガイドラインを遵守し、次のとおりプライバシーポリシー（以下「本ポリシー」といいます。）を定めます。

第1条（基本方針）

1. 運営者は、個人情報が個人の人格尊重の理念のもとに慎重に取り扱われるべきものであることに鑑み、個人情報の適正な取扱いに努めます。

2. 運営者は、個人情報の取扱いに関する法令、国が定める指針その他の規範を遵守するとともに、本ポリシーの内容を適宜見直し、その改善に努めます。

第2条（定義）

本ポリシーにおいて使用する用語の定義は、次の各号に定めるとおりとします。

1. 「個人情報」とは、個人情報保護法第2条第1項に定める個人情報をいいます。

2. 「個人データ」とは、個人情報保護法第16条第3項に定める個人データをいいます。

3. 「保有個人データ」とは、個人情報保護法第16条第4項に定める保有個人データをいいます。

4. 「要配慮個人情報」とは、個人情報保護法第2条第3項に定める要配慮個人情報をいいます。

5. 「利用者」とは、本サービスを利用する全ての者をいい、団体アカウントを保有する者及び部員として登録された者を含みます。

6. 「団体データ」とは、団体アカウントのもとに登録され、又は本サービスの利用に伴い生成される部員情報、的中記録、出欠記録、立順その他一切のデータをいいます。

7. 「生成AI機能」とは、第12条に定める人工知能技術を利用した機能をいいます。

8. 前各号に定めるもののほか、本ポリシーにおいて使用する用語の意義は、別途定める利用規約の定めに従うものとします。

第3条（適用範囲）

1. 本ポリシーは、本サービスの提供に関連して運営者が取得する個人情報の取扱いについて適用されます。

2. 本サービスからリンクされる第三者のウェブサイト又はサービスにおける個人情報の取扱いについては、本ポリシーは適用されず、当該第三者の定めるところによるものとします。

第4条（取得する情報の項目）

運営者は、本サービスの提供にあたり、次の各号に掲げる情報を取得します。

1. 団体アカウントの登録に関する情報

  • (1) 団体ID
  • (2) 団体名
  • (3) 電子メールアドレス（認証及びアカウント復旧のために使用します。）
  • (4) パスワード（Firebase Authentication において管理され、運営者はこれを平文で保持しません。）
  • (5) 利用規約及び本ポリシーへの同意の記録（同意した版、同意した日時及び同意を得た方法）

2. 部員に関する情報

  • (1) 氏名又はこれに代わる呼称
  • (2) 学年
  • (3) 性別
  • (4) 期（入部年次を表す番号）
  • (5) 個人ID（登録時に付与される識別符号）
  • (6) 弓具に関する記録（弓力、弦、矢その他の用具の変更の内容及びその年月日）

3. 練習及び記録に関する情報

  • (1) 的中記録（射数、的中数、矢ごとの結果及び矢所を含みます。）
  • (2) 立順及び立の構成
  • (3) 練習日及びタグ
  • (4) 出欠記録及び公式練習日の設定

4. お問い合わせに関する情報

  • (1) 電子メールアドレス
  • (2) お問い合わせの内容
  • (3) 添付された画像
  • (4) 送信時のログイン状態に応じて自動的に付加される団体ID、団体名、ログイン種別、個人ID及び氏名

5. 生成AI機能の利用に伴い送信される情報

  • (1) 利用者が入力したメッセージ
  • (2) 部員の氏名を含む部員一覧
  • (3) 回答の生成に必要な範囲の的中記録
  • (4) 利用者が写真ライブラリから選択し、又はカメラで撮影した画像及び利用者が選択したPDFファイル（立順表、的中記録表又は練習日程表を撮影したものであり、部員の氏名が含まれる場合があります。）

6. 利用者の端末上に保存される情報

  • (1) 表示テーマその他のアプリケーション設定
  • (2) チュートリアルの表示状態
  • (3) オフライン環境における利用のために一時的に保存される団体データ

運営者は、広告の配信を目的とした行動履歴の収集、第三者による広告識別子の利用及び位置情報の取得を行いません。

第5条（取得の方法）

1. 運営者は、次の各号に掲げる方法により個人情報を取得します。

  • (1) 利用者が本サービスの画面上において入力し、又は登録する方法
  • (2) 利用者が写真ライブラリから選択し、又はカメラで撮影した画像を送信する方法
  • (3) 本サービスの利用に伴い自動的に記録される方法

2. カメラ及び写真ライブラリへのアクセスは、立順表の読取機能を利用する場合に限り、利用者の端末のオペレーティングシステムを通じて利用者の許諾を得たうえで行うものとします。

第6条（利用目的）

運営者は、取得した個人情報を次の各号に掲げる目的の達成に必要な範囲において利用します。

1. 団体アカウント及び部員としての利用に係る本人確認、認証並びにログイン状態の維持のため

2. 的中記録及び出欠記録の保存、閲覧、集計並びに分析結果の表示のため

3. 団体内における記録の共有及び複数の端末間におけるデータの同期のため

4. 立順表の画像から立順を自動的に読み取り、記録の入力を補助するため

5. 生成AI機能において、利用者の質問に対する回答を生成するため

6. 利用者からのお問い合わせ、要望、相談等に対する調査及び回答の連絡のため

7. 本サービスの不具合の原因調査、復旧及び再発防止のため

8. 本サービスの品質の維持及び改善並びに新たな機能の検討のため

9. 本規約に違反する行為への対応のため

10. 法令又は行政機関の要請に基づく対応のため

第7条（利用目的の変更）

1. 運営者は、利用目的を変更する場合には、変更前の利用目的と関連性を有すると合理的に認められる範囲内において行うものとします。

2. 運営者は、前項により利用目的を変更した場合、変更後の利用目的について、本サービス上又は運営者の運営するウェブサイト上への掲示その他の適切な方法により、利用者に通知し、又は公表するものとします。

第8条（適正な取得）

運営者は、偽りその他不正の手段により個人情報を取得しないものとします。

第9条（要配慮個人情報）

1. 運営者は、本サービスにおいて要配慮個人情報を取得することを予定していません。

2. 利用者は、本サービスに要配慮個人情報を入力し、又は送信しないものとします。

第10条（未成年者の個人情報）

1. 本サービスは、学校の部活動その他の団体における利用を想定して提供されるものであり、未成年者の個人情報が登録されることが想定されます。

2. 未成年者が本サービスを利用する場合には、あらかじめ法定代理人の同意を得たうえで、当該団体の責任者の管理のもとで利用するものとします。

3. 団体アカウントの管理者は、部員の個人情報を登録するにあたり、あらかじめ当該本人及び必要に応じてその法定代理人から、登録及び本サービスにおける利用について必要な同意を取得する責任を負うものとします。

第11条（第三者提供）

1. 運営者は、次の各号のいずれかに該当する場合を除き、あらかじめ本人の同意を得ることなく、個人データを第三者に提供しません。

  • (1) 法令に基づく場合
  • (2) 人の生命、身体又は財産の保護のために必要がある場合であって、本人の同意を得ることが困難であるとき
  • (3) 公衆衛生の向上又は児童の健全な育成の推進のために特に必要がある場合であって、本人の同意を得ることが困難であるとき
  • (4) 国の機関若しくは地方公共団体又はその委託を受けた者が法令の定める事務を遂行することに対して協力する必要がある場合であって、本人の同意を得ることにより当該事務の遂行に支障を及ぼすおそれがあるとき
  • (5) 第14条に定める委託に伴い個人データが提供される場合
  • (6) 事業の承継に伴い個人データが提供される場合

2. 運営者は、個人情報保護法第29条の規定に基づき、第三者に個人データを提供したときは、法令の定めるところにより記録を作成し、保存するものとします。

第12条（生成AIサービスの利用）

1. 本サービスには、次の各号に掲げる機能（以下総称して「生成AI機能」といいます。）が含まれます。生成AI機能は、Google LLC が提供する Gemini API を利用して提供されます。

  • (1) 対話形式の質問応答機能
  • (2) 画像から立順表を読み取る機能
  • (3) 画像から的中記録表を読み取る機能
  • (4) 画像又はPDFから練習日程を読み取る機能

2. 生成AI機能を利用した場合、次の各号に掲げる情報が Google LLC に送信されます。当該送信は、運営者が Cloudflare, Inc. の提供する Cloudflare Workers 上で運用する中継サーバーを経由して行われます。中継サーバーは、利用者がログインしていることを確認したうえで、送信された情報をそのまま Google LLC に転送するものであり、送信された情報を保存しません。

  • (1) 利用者が入力したメッセージ
  • (2) 部員の氏名を含む部員一覧
  • (3) 回答の生成に必要な範囲の的中記録
  • (4) 利用者が選択し、又は撮影した画像及びPDFファイル。当該画像には、立順表又は的中記録表に記載された部員の氏名が含まれる場合があります。

3. 運営者は、Gemini API について有料の利用形態を選択しています。当該形態においては、前項により送信された情報は、回答及び読取結果の生成のために処理され、Google LLC のサービスの改善（機械学習を含みます。）には利用されません。ただし、同社の定める禁止利用の検知及び防止を目的として、送信された情報及び生成された回答が同社において一定の期間記録されることがあります。運営者は、前項の送信を、個人情報保護法第27条第5項第1号に定める委託として取り扱います。

4. Google LLC 及び Cloudflare, Inc. はいずれも米国に所在するため、前項の委託及び第2項の中継は、個人情報保護法第28条に定める外国にある第三者への提供に該当します。運営者は、同条の定めるところに従い、これらの会社が我が国の個人情報取扱事業者が講ずべき措置に相当する措置を継続的に講ずるために必要な体制を整備していることを確認したうえで、これを行います。

  • (1) 運営者は、これらの会社による相当措置の実施状況及び米国における個人情報の保護に関する制度の変更の有無を、少なくとも年に1回、定期的に確認します。
  • (2) 相当措置の継続的な実施に支障が生じたことを把握した場合、運営者は、必要な措置を講じるものとし、その実施の確保が困難となったときは、当該提供を停止します。
  • (3) 提供先の氏名、提供先が所在する外国の名称、相当措置の概要、確認の頻度及び方法その他個人情報保護法施行規則第18条第3項に定める事項については、第19条に定める窓口への求めに応じて提供します。

5. 米国における個人情報の保護に関する制度並びに Google LLC 及び Cloudflare, Inc. が講ずる個人情報の保護のための措置に関する情報は、次の各号に掲げるところにより確認することができます。

  • (1) 個人情報保護委員会が公表する当該国の制度に関する調査結果
  • (2) Google プライバシーポリシー（https://policies.google.com/privacy）
  • (3) Google API 追加利用規約その他 Google LLC が定める条件
  • (4) Cloudflare プライバシーポリシー（https://www.cloudflare.com/privacypolicy/）

6. 運営者は、Gemini API の利用形態を変更し、又は生成AI機能の提供に用いるサービスを変更する場合には、本ポリシーを改定のうえ周知します。

7. 生成AI機能により出力される回答及び読取結果について、運営者は、その正確性、完全性又は特定の目的への適合性を保証しません。

第13条（外国にある第三者への提供）

1. 前条に定めるもののほか、第14条に定める委託先は、米国その他日本国外に所在するサーバーにおいて個人データを取り扱う場合があります。

2. 運営者は、外国にある第三者に個人データを提供する場合、個人情報保護法第28条の定めるところに従い、あらかじめ本人の同意を得るか、又は当該第三者が個人情報保護法に相当する基準に適合する体制を整備していることを確認したうえで、必要な措置を講じるものとします。

第14条（個人データの取扱いの委託）

1. 運営者は、利用目的の達成に必要な範囲内において、個人データの取扱いの全部又は一部を第三者に委託することがあります。

4. Gemini API を通じて送信される情報及びその中継の詳細については、第12条に定めるところによります。

第15条（共同利用）

運営者は、本ポリシーの効力発生日現在、個人データの共同利用を行っていません。

第16条（安全管理措置）

運営者は、個人データの漏えい、滅失又は毀損の防止その他の個人データの安全管理のため、次の各号に掲げる措置を講じます。

1. 基本方針の策定　個人データの適正な取扱いの確保のため、本ポリシーを策定し、公表しています。

2. 組織的安全管理措置　お問い合わせの内容を含む個人データへのアクセス権限を運営者に限定し、本サービスからの読取り、変更及び削除を禁止する設定を行っています。

3. 技術的安全管理措置

  • (1) 通信経路の TLS による暗号化
  • (2) Firebase セキュリティルールによるアクセス制御。団体データ（記録、部員情報その他団体アカウントのもとに保存される情報をいいます。）については、団体アカウントを保有する本人及び所属を証明した部員に限りアクセスできる設定としています。
  • (3) 前号にかかわらず、団体IDと当該団体の登録メールアドレスとの対応については、ログインの前に参照できる設定としています。本サービスのログインは団体IDを用いて行う一方、認証の基盤はメールアドレスによるため、認証に先立って当該対応を参照する必要があるためです。団体名、登録の日時及び同意の記録は、当該団体アカウントを保有する本人に限り参照できる設定としています。
  • (4) ライブ共有機能において Realtime Database に一時的に保持されるデータ（記録中の的中、氏名及び立順に限られます）については、団体ごとに発行される推測困難な文字列を保存先の名称として用い、当該文字列を保有しない者が参照できない設定としています。当該文字列は、所属を証明した利用者のみが取得できます。当該データは、共有の終了後に削除されます。
  • (5) 前号の措置は、当該文字列を過去に取得した者による参照を妨げるものではありません。運営者は、より強固な分離のための改善を継続的に検討しています。
  • (6) URL による共有機能を利用した場合、当該 URL を保有する者は、当該記録に限り参照することができます。編集可能な URL と閲覧のみの URL は別個に発行され、合言葉を設定した場合は、当該合言葉を知らない者は参照できません。共有には有効期限を設定することができ、期限の経過後は、Realtime Database の設定により参照できなくなります。
  • (7) Firebase App Check による不正なアクセスの防止
  • (8) パスワードの平文での保持の禁止

4. 物理的安全管理措置　個人データは、委託先が管理するデータセンターにおいて保管されます。

5. 外的環境の把握　個人データを保管する国における個人情報の保護に関する制度を把握したうえで、安全管理措置を講じています。

なお、本条に定める措置のうち、その内容を明らかにすることにより個人データの安全管理に支障を及ぼすおそれのあるものについては、記載を省略しています。当該事項については、第19条に定める窓口への求めに応じて、遅滞なく回答します。

第17条（従業者及び委託先の監督）

1. 運営者は、個人データを取り扱う従業者を置く場合、当該従業者に対し、個人データの安全管理が図られるよう必要かつ適切な監督を行います。

2. 運営者は、第14条に定める委託先に対し、個人データの安全管理が図られるよう必要かつ適切な監督を行います。

第18条（保有個人データの保存期間及び消去）

1. 団体データ及び部員情報は、当該団体アカウントが存続する間、保存されます。

2. 利用者は、本サービスの機能により、部員情報及び記録を随時削除することができます。
